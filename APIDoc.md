# API and Data Findings

What we learned about the external APIs and data sources for the Space Mission Design Game. Checked on 14 November 2026. The stack and reuse plan are in [tech.md](tech.md); credits are in [CREDITS.md](CREDITS.md).

## Summary

- **Only two sources are live APIs:** Launch Library 2 (rockets) and CelesTrak (real satellite positions, an optional extra). Everything else is a document, a file set or a tool that we read once and copy numbers from.
- **The game never calls an API while it runs.** Each source is downloaded once into JSON files in the repo, so the game works offline and every player gets the same numbers.
- **Launch Library 2 is tested and in use.** A script downloads it, and a curated list of ten rockets plus a rideshare option is in [data/launchers.json](data/launchers.json).
- **Two things come from launch providers, not from Launch Library 2:** the rideshare price and three capacities to sun-synchronous orbit. See "Values from launch providers".
- **The other sources are not yet used.** Their links load, but nobody has read their contents or extracted data from them.
- **The current game covers Earth orbits only.** Three sources are needed only for Moon and Mars missions and are kept for a future version.

## How we get each JSON file

### Files that exist now

All three are in `data/` and were produced on 14 November 2026.

| File | How we get it | Source |
|---|---|---|
| [data/launchers.raw.json](data/launchers.raw.json) | **Generated by script.** `scripts/fetch-launchers.ts` sends two GET requests to the Launch Library 2 launcher endpoint (100 rockets per page, 161 in total). It keeps the rockets that have both a low-Earth-orbit capacity and a launch cost (31), renames the fields, computes the success rate, and sorts by capacity. | Launch Library 2 API |
| [data/launchers.curation.json](data/launchers.curation.json) | **Written by hand.** We read the raw file and picked ten rocket ids that cover the range from small to heavy, each with a one-line reason. Also typed by hand here: the rideshare entry, three published capacities to sun-synchronous orbit, and the general factor for the other rockets. | Our own choices; launch providers' pages |
| [data/launchers.json](data/launchers.json) | **Generated by the script.** It takes the ten picked ids from the raw data, applies the overrides from the curation file (the display name "LVM3" and three capacities to sun-synchronous orbit), estimates that capacity for the other seven rockets with the general factor, and puts the hand-written rideshare entry first. This is the file the game reads. | Raw file + curation file |

To take a fresh copy from the API and rebuild both generated files, run this from the repo root:

```
node --experimental-strip-types scripts/fetch-launchers.ts --live
```

To rebuild only `data/launchers.json` after editing the curation file, without calling the API:

```
node --experimental-strip-types scripts/fetch-launchers.ts --offline
```

Use `--offline` for every curation change: a new price, a new capacity, or a different choice of rockets (all 31 candidates are in the raw file). It leaves the Launch Library 2 values exactly as they were fetched. Never edit the two generated files by hand, because the next run overwrites them.

## Launch Library 2

A free public database of rockets and launches, run by The Space Devs, a volunteer nonprofit. It is not an official agency source.

| Item | Finding |
|---|---|
| Real API | `https://ll.thespacedevs.com` (current data) |
| Development mirror | `https://lldev.thespacedevs.com` (no rate limit, stale data) |
| Endpoint we use | `/2.2.0/config/launcher/?mode=detailed&active=true&limit=100&format=json` |
| Rate limit | 15 calls per hour on the free tier. One import uses two calls. |
| Terms | Free to use and share. Attribution is encouraged but not required. Accuracy is not guaranteed. ([Terms of use](https://github.com/TheSpaceDevs/Tutorials/blob/main/faqs/faq_TSD.md#terms-of-use)) |
| Credit | "Data from Launch Library 2 by The Space Devs" |

`mode=detailed` matters: without it, the list leaves out capacity and cost, and each rocket would need its own call.

### Fields we use

| API field | Our field | Game rule |
|---|---|---|
| `full_name` | `name` | Shown in the launcher picker |
| `leo_capacity` | `leoCapacityKg` | Mass check: spacecraft plus margin must weigh less than this |
| `gto_capacity` | `gtoCapacityKg` | Not used in the first version (low Earth orbits only). Empty means the API has no value, not that the rocket cannot reach high orbits |
| `launch_cost` | `launchCostUsd` | Subtracted from the mission budget |
| `successful_launches`, `failed_launches` | `successRate` | Chance of launch failure in the simulation |
| `reusable`, `image_url`, `info_url`, `manufacturer.name` | same, in camelCase | Info card |

The API also has launches, pads, agencies, astronauts and space stations. We do not use them.

### Fields we add

These are not in the API. They are typed into the curation file or computed by the script.

| Our field | On | Meaning |
|---|---|---|
| `ssoCapacityKg` | Every launcher | Capacity to sun-synchronous orbit. See "Capacity to sun-synchronous orbit" |
| `sources` | Every launcher | Where each number or rule that is not from Launch Library 2 comes from (display names are not covered). One entry lists the `fields` it covers, a `data_quality` flag and the `source`; published values also have a `url` and the date `checked`; a `note` is optional |
| `costPerKgUsd`, `includedKg` | Rideshare only | Price model: `launchCostUsd` covers a satellite of up to `includedKg`; each kg above that costs `costPerKgUsd` |
| `fixedOrbit` | Rideshare only | The orbit the player cannot change, as `type` and `altitudeKm` |
| `note` | Rideshare only | A sentence for people reading the file; the game does not need it |

`data_quality` keeps the name used in [tech.md](tech.md) and the agent rules, so it is the one field that is not in camelCase. The agent rules give measured / representative / estimated as examples. The launcher data uses three values so far:

| Value | Meaning |
|---|---|
| `published` | Stated by the provider or agency in its own document; we copied the figure |
| `estimated` | Derived by us from other figures |
| `game-design` | Chosen by us for the game; not a real-world figure |

### Data quality

- **Gaps:** 161 active rockets, but only 31 have both a capacity and a cost.
- **Variants:** the same rocket appears several times (five Soyuz 2.1 rows). Launch counts are per variant, so PSLV shows 12 flights instead of its full history.
- **Doubtful values:** for example Angara A5 at $31M.
- **Empty is not zero:** a missing high-orbit capacity means the API has no value, not that the rocket cannot get there. The Space Launch System is an example.

Because of this, the game uses a hand-picked list, not the raw data.

### How the import works

```
node --experimental-strip-types scripts/fetch-launchers.ts --offline  # no API call: rebuild from the raw file
node --experimental-strip-types scripts/fetch-launchers.ts --live     # real API
node --experimental-strip-types scripts/fetch-launchers.ts --dev      # development mirror
```

The script needs exactly one of these modes. With no mode, or a mistyped one, it prints the three modes and changes nothing. It also stops, and leaves the game file untouched, if any launcher ends up without a valid, sourced `ssoCapacityKg` or is listed twice.

It needs Node 22.6 or newer and has no dependencies.

| File | Contents | Edit by hand? |
|---|---|---|
| [scripts/fetch-launchers.ts](scripts/fetch-launchers.ts) | The import script | Yes |
| [data/launchers.curation.json](data/launchers.curation.json) | Which rockets are in the game, why, and the manual entries | Yes: this is where rockets are swapped |
| [data/launchers.raw.json](data/launchers.raw.json) | All 31 candidates from the API | No, generated |
| [data/launchers.json](data/launchers.json) | What the game reads: the picks plus manual entries | No, generated |

If a picked rocket disappears from the API, the script stops with an error and leaves the game file untouched.

The API import is a one-time step. The JSON files are committed and used as fixed reference data; there is no scheduled refresh. Run with `--live` again only to take a new snapshot of the rockets, and then re-check the curated list below. Every curation edit uses `--offline`.

### The curated list

Launch Library 2 values are from the real API on 14 November 2026. The sun-synchronous column is ours: a figure with ~ is an estimate (see "Capacity to sun-synchronous orbit").

| Vehicle | To low Earth orbit | To sun-synchronous orbit | To high orbit | Cost | Success rate | Role in the game |
|---|---|---|---|---|---|---|
| Rideshare (shared launch) | 200 kg | 200 kg | no | from $0.35M | 98% | Cheapest, but the orbit cannot be chosen |
| Electron | 300 kg | 200 kg | no | $6M | 96% | Smallest dedicated rocket |
| Firefly Alpha | 1,000 kg | 630 kg | no | $15M | 57% | Cheap per kg, risky |
| Vega-C | 3,300 kg | ~1,980 kg | no | $48M | 88% | European small launcher |
| PSLV | 3,800 kg | 1,750 kg | 1,200 kg | $21M | 83% | Low-cost medium launcher |
| Soyuz 2.1b | 8,200 kg | ~4,920 kg | 3,250 kg | $80M | 100% | Reliable, expensive for its size |
| LVM3 | 10,000 kg | ~6,000 kg | 5,000 kg | $46M | 100% | Good value for heavier spacecraft |
| Ariane 62 | 10,900 kg | ~6,540 kg | 5,100 kg | $85M | 100% | European medium-heavy |
| Falcon 9 Block 5 | 22,800 kg | ~13,680 kg | 8,300 kg | $52M | 99.8% | Most flown, very reliable |
| Falcon Heavy | 63,800 kg | ~38,280 kg | 26,700 kg | $90M | 100% | Heavy lift |
| Space Launch System Block 1 | 95,000 kg | ~57,000 kg | no | $2,000M | 100% | Overkill on purpose: bigger is not better |

**Rideshare is not from the API.** Its price is SpaceX's published rideshare price for 2026 flights: $350,000 for a satellite of up to 50 kg, then $7,000 for each extra kg (see "Rideshare price"). Its 200 kg limit and 98% success rate are game-design values, and so is its fixed orbit: sun-synchronous at 525 km ([design.md](design.md) section 4.3). It has four fields the other rockets lack: `costPerKgUsd`, `includedKg` and `fixedOrbit`, which the simulation must handle, and a `note`.

**How the game uses the list** (design.md): `successRate` is the chance that the launch succeeds, and a failed launch ends the mission. Rockets that cost more than the mission's whole budget are shown locked. Capacity to sun-synchronous orbit is lower than the listed low-Earth-orbit capacity; the game reads it from `ssoCapacityKg`.

## Values from launch providers

Launch Library 2 has no rideshare price and no capacity to sun-synchronous orbit. Both come from the launch providers' own pages, checked on 14 November 2026. We copied figures only, no text or images.

### Rideshare price

| Item | Finding |
|---|---|
| Source | SpaceX Smallsat Rideshare Program, online price tool: [rideshare.spacex.com/search](https://rideshare.spacex.com/search) |
| Price for 2026 flights to sun-synchronous orbit | $350,000 for up to 50 kg, then $7,000 for each extra kg |
| In the data | `launchCostUsd` 350000, `includedKg` 50, `costPerKgUsd` 7000 |
| How it was checked | First from search-engine copies of the tool's result pages ($0.35M for 10 kg, $0.42M for 60 kg, $1.4M for 200 kg) and trade articles from 2026. Then **confirmed by hand in a browser, in the tool itself, on 14 November 2026**: 50 kg costs $0.35M and 60 kg costs $0.42M (TODO T3.1). |

- The price depends on the flight year. The value we had before ($325,000, then $6,500 per kg) was the 2025 price. Reports that cite the same tool give $7,500 per kg for 2027 flights.
- The rideshare option in the game is generic. It uses SpaceX's price because that price is published.

### Capacity to sun-synchronous orbit

| Rocket | To low Earth orbit (our data) | Published capacity to sun-synchronous orbit | Ratio | Source | How it was checked |
|---|---|---|---|---|---|
| Electron | 300 kg | 200 kg at 500 km | 0.67 | [Rocket Lab, Electron Payload User's Guide 7.0](https://rocketlabcorp.com/assets/Electron-Payload-User-Guide-7.0-v6.pdf) | Rocket Lab's site refuses automated access. Read from search-engine copies of the guide and of Rocket Lab's August 2020 announcement of the same figures. Then **confirmed by hand in a browser, in the guide itself, on 14 November 2026** (TODO T3.2) |
| Firefly Alpha | 1,000 kg | 630 kg at 500 km | 0.63 | [Firefly Aerospace, Alpha page](https://fireflyspace.com/alpha/) | Page read directly |
| PSLV | 3,800 kg | 1,750 kg at 600 km | 0.46 | [ISRO, PSLV page](https://www.isro.gov.in/PSLV_CON.html) | Page read directly |

How the data is built:

- **Published figure where we have one.** It is stored as `ssoCapacityKg` with `data_quality: published`. We sourced the three dedicated rockets that the Wildfire Watch budget allows.
- **General factor for the rest.** The other seven rockets get `leoCapacityKg` × **0.6**, rounded to the nearest kg, with `data_quality: estimated`. 0.6 is the mean of the three ratios above (0.59), rounded to one decimal. All seven cost more than the Wildfire Watch budget, so the estimate does not affect the first mission.
- **Rideshare keeps its own limit.** Its 200 kg is already a limit to its fixed sun-synchronous orbit, so the factor is not applied to it.
- **One figure per rocket.** The game uses it for every sun-synchronous altitude. Real capacity falls as altitude rises, so this is a simplification.

Limits of these figures:

- The ratios use the low-Earth-orbit capacity in our data, because that is the number the factor multiplies. Providers' own figures differ a little: Firefly's page gives 1,030 kg to a 300 km orbit, and ISRO publishes no low-Earth-orbit figure for PSLV.
- ISRO gives the 1,750 kg in its section on the PSLV-XL configuration. Launch Library 2 has several PSLV rows; ours is the one named "PSLV".
- The ratios differ a lot (0.46 to 0.67), so the general factor can be wrong by a third for a single rocket. Replace an estimate with a published figure whenever a later mission makes that rocket affordable.

## CelesTrak (optional extra)

A live API that returns the current orbits of real satellites, such as the International Space Station. tech.md lists it as a late extra for showing real satellites in the low-orbit view. The data is updated several times a day, so results change between calls. We confirmed that the endpoint responds; we have not used it.

## What to trust

- **NASA sources are official, but not game-ready.** Reducing each part or instrument to a few numbers is our own simplification.
- **Launch Library 2 is the least reliable source.** It is community-maintained and says so itself. Check any rocket's numbers before quoting them.
- **Cost figures are approximations.** The game and the project page should say so.
- **Capacity to sun-synchronous orbit is an estimate for seven rockets.** Only Electron, Firefly Alpha and PSLV have a published figure.
- **Record the source of every number** in the JSON files. Validity is a judging criterion.
